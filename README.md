# DayDreamingg-g Assistant 🤖

**Учебный Windows-лаунчер на Python с графическим интерфейсом.**

> *From vibe coding to understanding code — one commit at a time.*

## О проекте

DayDreamingg-g Assistant (Jarvis) — мой практический проект для изучения Python, объектно-ориентированного программирования и принципов написания понятного, поддерживаемого кода.

Программа позволяет запускать часто используемые приложения из одного окна. Если подходящее окно уже открыто, лаунчер пытается переключиться на него вместо повторного запуска.

**Главная цель репозитория — не просто создать работающую программу, а научиться самостоятельно понимать, писать, отлаживать и улучшать код.** Проект развивается поэтапно: от простого запуска процессов до GUI, ООП и разделения модулей.

## Возможности

- Графический интерфейс с плитками Discord, Spotify, Steam и Google Chrome.
- Запуск приложений через `subprocess`.
- Поиск видимых окон и попытка переключения на уже запущенную программу через Windows API.
- Изменение оформления плиток при наведении курсора.
- Диалог с описанием ошибки при неудачном запуске приложения.

## Четыре принципа ООП на примере Jarvis

В проекте я изучаю четыре основных принципа объектно-ориентированного программирования на конкретном классе `AppTile`.

| Принцип | Где используется | Как проявляется в проекте |
| --- | --- | --- |
| **Инкапсуляция (Encapsulation)** | Класс `AppTile`: `__init__()`, `set_tile_color()`, `mousePressEvent()` | Создание плитки, её оформление и реакция на нажатие собраны внутри одного объекта. Это объединение связанных данных и поведения; строгого ограничения доступа к атрибутам здесь нет. |
| **Наследование (Inheritance)** | `class AppTile(QWidget)` и `super().__init__()` | Собственный виджет расширяет `QWidget` и использует унаследованные методы: `setFixedSize()`, `setLayout()`, `setStyleSheet()` и другие. |
| **Полиморфизм (Polymorphism)** | Переопределённые `enterEvent()`, `leaveEvent()` и `mousePressEvent()` | Qt вызывает стандартные обработчики событий виджета, а объект `AppTile` выполняет собственную реализацию — подсвечивает плитку или испускает сигнал `clicked`. |
| **Абстракция (Abstraction)** | Создание плитки через `AppTile(display_name, icon_path)` | Вызывающему коду достаточно передать название и иконку. Детали создания `QLabel`, `QVBoxLayout` и настройки QSS остаются внутри класса. |

Например, для создания плитки достаточно:

```python
tile = AppTile("Discord", "icons/discord.ico")
```

А её поведение при наведении и нажатии реализовано внутри `AppTile`, а не повторяется для каждого приложения.

## Организация кода

Проект постепенно приводится к простой модульной структуре:

```text
Assistant/
├── main.py             # GUI, создание плиток, логика запуска
├── window_manager.py   # Поиск и активация окон через Win32 API
└── icons/              # Изображения приложений
```

В ходе рефакторинга применяются следующие практики:

- **DRY:** одна конфигурация приложений и один цикл создания плиток вместо повторяющихся блоков.
- **Separation of Concerns:** UI и операции с окнами Windows выделяются в отдельные части.
- **Понятные имена:** например, `display_name` для надписи на плитке и `title_pattern` для поиска окна.
- **Небольшие функции:** поиск окна, активация окна и запуск процесса имеют разные задачи.

Это небольшой учебный проект, поэтому цель — разумная структура без избыточных архитектурных слоёв.

## Установка и запуск

**Требования:** Windows и Python 3.10 или новее.

1. Клонируйте репозиторий и откройте его каталог.
2. Установите зависимости:

   ```bash
   python -m pip install PyQt6 pywin32
   ```

3. Проверьте пути к исполняемым файлам в конфигурации `apps` в `main.py`. Пока они указаны для конкретной установки Windows.
4. Запустите приложение:

   ```bash
   python main.py
   ```

Изображения приложений должны находиться в папке `icons/`.

## Текущие ограничения

- Программа рассчитана на Windows.
- Пути к `.exe` пока заданы вручную.
- Поиск окон основан на заголовках, поэтому отдельные окна могут совпадать с шаблоном; для Steam используется точное совпадение `Steam`.
- Если открыто несколько подходящих окон, выбор конкретного окна пока не является отдельной настраиваемой функцией.
- Голосовое управление ещё не реализовано.
